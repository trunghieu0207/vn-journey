# Chế độ "Chạy trạm" — Kế hoạch thực hiện

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm kiểu phòng thứ ba `tram`: mỗi team tự chạy trạm trên bản đồ, nhặt key theo câu đố gợi ý, gom đủ key thì mở map lịch sử (3 câu + câu ghép mảnh) để về đích.

**Architecture:** Phòng `tram` dùng lại nhánh **tem** của phòng chơi đơn (bảng `stamps`, không `ownership`) nhưng có team nhiều người như phòng team. Mọi trạng thái riêng của mode (key, gợi ý, thời kỳ, ngôi sao, map đặc biệt) nằm trong một cột JSON `teams.tram`, xử lý trong module mới `server/game/tram.js`. Nội dung (thời kỳ, câu đố gợi ý) đọc từ `data/periods.json` + `data/key-hints.json` lúc khởi động, chỉ lấy mục `reviewed: true`; test bơm nội dung giả qua tùy chọn `tramContent`.

**Tech Stack:** Node 22.23.4 built-in (`node:http`, `node:sqlite`, `node:test`), HTML/CSS/JS thuần, pnpm. 0 dependency.

**Spec:** `docs/superpowers/specs/2026-11-09-tram-mode-design.md` — đọc trước, kế hoạch này dẫn chiếu mục của spec (§3.4…).

## Global Constraints

- 0 dependency; chỉ `node:*`; chỉ `pnpm` (không `npm`/`npx`).
- Hai kiểu phòng cũ (`team`, `solo`) giữ nguyên hành vi: `pnpm run test` (143 test cũ) phải qua sau mỗi task.
- Đáp án, vị trí key chưa lộ, tỉnh của gợi ý, tên thời kỳ chưa mở, thứ tự đúng của mảnh ghép **không bao giờ** gửi client.
- Không emoji, không `confirm()`, không class/id/file kiểu quảng cáo (`ad`, `banner`, `promo`, `popup`…).
- File mới trong `public/` → thêm vào whitelist `server/static.js`. Mọi API phía client qua `api()` của `shared/api.js`.
- Đổi `db/schema.sql` → `pnpm run db:reset` (xóa phòng).
- Hằng số luật (spec): N key mặc định **5** (cho 3–7); gợi ý mỗi **3** tỉnh đúng; luật cứu ở **nửa thời lượng**; câu tỉnh 30 giây / 15 giây đủ điểm; khóa sai **30 giây**; câu map **500** điểm, 45 giây / 20 giây đủ điểm; câu ghép **+1000**; thưởng về đích **phút còn lại (làm tròn xuống) × 30**; thời lượng phòng `tram` ≥ **30** phút.
- Từ ngữ hiển thị dùng bộ "Lữ hành" (không từ quân sự).

## Review Focus

1. **Tạm dừng / tiếp tục giữa câu map đặc biệt hoặc lúc khóa câu ghép** — giờ câu, khóa và mốc luật cứu phải dời đúng bằng khoảng tạm dừng (test ở Task 7 + Task 5).
2. **Hai người cùng team nộp câu map / câu ghép cùng lúc** — người sau nhận lỗi `no-pending` / `already-done`, điểm không cộng hai lần (test ở Task 7).
3. **Người vào muộn / tải lại trang** — thấy đủ sổ gợi ý, key, mảnh đã lộ, trạng thái map (test `teamView` ở Task 8).
4. **"Chơi lại"** — xóa sạch key, gợi ý, thời kỳ, ngôi sao, tem; trận mới rải lại (test ở Task 4).
5. **Hết giờ khi team đang ở map đặc biệt** — điểm đã có (tỉnh chưa đi + câu map đã đúng) giữ nguyên, không có thưởng về đích (test ở Task 8).

## Hình dạng dữ liệu dùng chung

**`teams.tram` (JSON, server-only):**
```js
{
  period: 'van-lang',            // id thời kỳ (random lúc bắt đầu, KHÔNG gửi client trước khi mở map)
  need: 5,                       // = rooms.key_count
  keys: [{ province: 'hue', piece: 2, hint: 0 /*0 chưa gợi ý,1,2*/, hintAt: null, found: false, foundAt: null }],
  hints: [{ key: 0, level: 1, text: '…', at }],   // sổ gợi ý theo thứ tự nhận (client nhận text + level + at)
  correct: 0,                    // số tỉnh trả lời đúng (mốc gợi ý)
  rescued: false,
  star: 'ready' | 'armed' | 'used',
  stage: 'map' | 'special' | 'puzzle' | 'done',
  openedAt: null, free: 0,       // lúc mở map; điểm tỉnh chưa đi đã cộng
  special: { done: 0, seen: ['van-lang-03'], pending: null /*{ id, order, at, star }*/, lockedUntil: null },
  puzzle: { lockedUntil: null, tries: 0 },
  finishedAt: null, finishBonus: 0,
}
```

**Nội dung (sau khi lọc `reviewed`)** — `ctx.tram = { periods: Map<id, Period>, hints: Map<provinceId, Hint[]> }`:
```js
Period = { id, name, years, scene: { color, icons: [3 tên icon], blurb },
           questions: [{ id, kind: 'choice', content, options: [4], answer: 0..3, explanation, level, sources }],
           puzzle: { text, explanation, sources, splits: { '3': [...3 chuỗi], '4': [...], …, '7': [...] } } }
Hint   = { level: 1 | 2, text, sources, basedOn }
```
